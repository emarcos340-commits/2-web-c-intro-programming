# Proyecto Final - Página Web con HTML

Este proyecto consiste en una página web creada con HTML como parte del proyecto final del curso.

## 📌 Contenido del proyecto
- Uso de etiquetas semánticas (html, head, body, title, meta)
- Títulos con h1, h2…
- Párrafos con `p`
- Imágenes con `img`
- Enlaces con `a`
- Listas con `ul`
- Formulario con `form`, `input`, `label`
